# DyMES-disease-transmission

## Installation
To set up this repository, clone the repo on your local machine.

## Usage
To reproduce the simulations and figures in the paper, run `fmd.ipynb`, `hpai.ipynb`, and `ndv.ipynb`. For additional information on the NDV (medium c0/medium d0) constraint satisfaction behavior for lower tau and higher K, run `ndv_high_K_tests.ipynb`
